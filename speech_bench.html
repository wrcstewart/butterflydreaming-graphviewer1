BD speech bench

Can a phone synthesise a corpus passage in the browser, fast enough to be worth having?

Passage

Contains the names that matter: Li Bai, Du Fu, Laozi, Zhuangzi, Tao Te Ching. Listen for how it says them — that is what the lexicon will have to fix.

Run

Each engine downloads a model on first run and caches it. Use wi-fi. Piper voice ~60 MB. Kokoro size depends on the precision below. q8 on WebGPU is off-spec — it measures the wrong configuration, not the engine, so try fp16 before judging speed.

Pronunciation lexicon (espeak phonemes)

One per line, word = phonemes. Piper phonemises with espeak-ng, which reads [[...]] in the text as literal phonemes — so this is pure text substitution before synthesis, and needs no change to the model. These are first guesses: adjust by ear, since only you can hear the result.
