Voice compare

One voice, on text it was trained on and text it has never seen. The pair is the point — either alone is easy to misread.
Delivered exactly as BD delivers it: pace 1.209, 504 ms after a full stop, 180 ms after a comma break — all imported from speech_timing.js, the same definitions BD itself uses.

Trained on this

Prompts 0001–0003 of the Tao set, read into the session itself. A fine-tune reproduces its own sentences best, so this is the upper bound — the most the voice can do, not what it will usually do.

Never heard, same text and register

Chapters 20 and 22 — beyond the prompt set, which stops at chapter 19, so no voice trained from it can have heard these however many prompts the reader got through. Same translation, same unhurried rhythm. This is the honest test: it isolates generalisation from memorisation, because nothing but the training set differs.

Never heard, different register

Ordinary modern prose with none of the Tao's cadence, written for this page rather than taken from a prompt set — so it is unseen by every voice, not just the latest one. Where a thin fine-tune usually falls down hardest, and the closest of the four to what BD actually reads aloud.

Snow White — the opening of the tale, as BD holds it

The author's choice of test case: the first two sentences of Snow White from BD's own Grimm material, node f796c44e. Four clauses chained on "and", two hyphenated compounds, and a narrative cadence nothing like the Tao's — so it tests register and phrasing at once.
It is also the only card where a comma pause is audible: BD reads a sentence whole up to 150 characters and only breaks a longer one at a comma. At 300 characters this splits into three, giving one 180 ms comma break and one 504 ms full stop. Listen to where the first split falls — it strands "and her embroidery frame was of ebony" as its own 38-character fragment, which is the splitter working as designed and may or may not sound right.

Thomas Hardy — verse, which BD reads differently

The opening stanza of His Visitor, node bcfa0635, from BD's own Hardy material. BD detects verse and changes how it reads — line by line rather than sentence by sentence, at SPEAK_VERSE_SCALE, 8% slower than prose, with the short 180 ms gap between lines. This card uses the same looksLikeVerse BD uses, so what you hear is what a stanza will sound like in the graph. Unseen by the voice, and in a register the training set has none of.
